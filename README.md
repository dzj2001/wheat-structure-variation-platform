### 小麦基因组结构变异检测平台使用教程
####  一、平台简介
该平台是一个基于深度学习的Web端基因组分析工具，采用B/S架构，通过SSH连接远程高性能计算服务器，调用优化后堆叠沙漏网络模型，实现对小麦基因组结构变异（缺失、重复、倒位等）的精准检测与分型。
####  二、使用步骤
第一步：连接服务器
打开平台主页，确认顶部导航栏显示服务器连接状态（绿色表示连接正常），系统已通过SSH持久化连接与远程计算服务器建立安全通道。
第二步：配置分析文件
在文件管理模块中：

1.通过文件浏览器浏览远程服务器目录结构

2.选择待分析的BAM比对文件、BAI/CSI索引文件、FAI索引文件

3.选择对应的PT深度学习模型文件

4.如需上传本地数据，使用大文件分块上传功能（支持断点续传和实时进度监控）

####  第三步：选择预训练模型
模型文件  适用场景  检测内容

BASIC4_Short.pt	Illumina  短读长数据  缺失、重复、倒位三种基本变异

BASIC4ZYG_Short.pt  Illumina短读长数据	基本变异 + 纯合/杂合判断

BASIC7_Short.pt	Illumina短读长数据	基本变异 + INVDUP、INVDEL等复合型变异

BASIC4_LONG.pt	PacBio长读长数据	更大范围的复杂结构变异

####  第四步：配置检测参数
在检测配置模块中设置以下参数：

CPU核心数：根据服务器资源合理配置，核心数越高计算速度越快

SV类别（必须匹配所选模型）：

1. BASIC4：检测缺失、重复、倒位

2. BASIC4ZYG：检测缺失、重复、倒位 + 纯合/杂合判断

3. BASIC7：检测基本变异 + INVDUP、INVDEL等复合型变异

BAM类型（必须与原始数据类型严格一致）：

1. SHORT（短读长）：Illumina测序数据，读长短但精度高

2. LONG（长读长）：PacBio测序数据，读长长可检测更大范围变异

染色体选择：

全选：全基因组分析

自定义选择：针对特定染色体（如Chr6D）进行定向分析，节省计算资源

####  第五步：生成并验证配置文件

1. 点击“生成配置”按钮

2. 系统自动整合所有参数，生成 data.yaml 与 model.yaml 两个标准化配置文件

3. 自动上传至远程服务器工作目录

4. 使用“查看配置”功能预览确认：检查文件路径是否正确；确认模型与数据类型匹配；验证所有参数无误

####  第六步：启动检测任务
确认所有参数无误后，点击“开始检测”按钮

系统自动执行：

通过SSH连接远程服务器

基于 data.yaml 和 model.yaml 组装分析命令

触发后端深度学习检测引擎

任务自动转入后台异步执行，可关闭页面而不影响任务运行

####  第七步：监控任务进度
任务执行期间：

进度条：动态显示任务执行阶段（启动→分析执行→结果生成）

状态提示：实时更新当前任务状态

无需等待：任务后台独立运行，可随时返回查看

####  第八步：查看实时日志

在实时日志模块（深色终端风格界面）中：

实时查看SSH连接状态、文件传输进度、命令执行输出

监控错误信息和警告提示

便于快速定位和排查问题

####  第九步：下载检测结果
任务完成后：

“检测报告下载”功能自动激活

点击获取VCF格式结果文件

完成分析流程
