### 小麦基因组结构变异检测平台使用教程
####  一、平台简介
该平台是一个基于深度学习的Web端基因组分析工具，采用B/S架构，通过SSH连接远程高性能计算服务器，调用优化后堆叠沙漏网络模型，实现对小麦基因组结构变异（缺失、重复、倒位等）的精准检测与分型。
####  二、使用步骤
第一步：连接服务器
打开平台主页，确认顶部导航栏显示服务器连接状态（绿色表示连接正常），系统已通过SSH持久化连接与远程计算服务器建立安全通道。
第二步：配置分析文件
在文件管理模块中：
1.通过文件浏览器浏览远程服务器目录结构
2.选择待分析的BAM比对文件、BAI/CSI索引文件、FAI索引文件
3.选择对应的PT深度学习模型文件
4.如需上传本地数据，使用大文件分块上传功能（支持断点续传和实时进度监控）
####  第三步：选择预训练模型
模型文件  适用场景  检测内容
BASIC4_Short.pt	Illumina  短读长数据  缺失、重复、倒位三种基本变异
BASIC4ZYG_Short.pt  Illumina短读长数据	基本变异 + 纯合/杂合判断
BASIC7_Short.pt	Illumina短读长数据	基本变异 + INVDUP、INVDEL等复合型变异
BASIC4_LONG.pt	PacBio长读长数据	更大范围的复杂结构变异

如需上传本地数据，使用大文件分块上传功能（支持断点续传和实时进度监控）
